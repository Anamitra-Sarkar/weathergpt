## 3. Architecture Delivered

```
User Q (hi/bn/en + Hinglish, village/pincode/lat,lon)
 → Intent Parser → LocationResolver (Gazetteer 8 + Nominatim) → TimeParser (tomorrow afternoon 12–18 IST) → Horizon short/medium/climate
 → RetrievalPlanner (16-step, horizon-pruned) → Decoders (IMD JSON, Open-Meteo Ensemble, GFS GRIB2 placeholder, CAP XML, WIS2 MQTT stub)
 → CEOs (22 fields, provenance) → Temporal/Spatial/Semantic gates → Ranker (authority 0.4 + freshness 0.25 + spatial 0.2 + quality 0.15)
 → WIO (weather + warning + agreement + disagreements) → RADE (2-scenario MDP, max EU) → Reviewer → LLM Explainer (WIO only)
```

Files: `app/schemas/ceo.py`, `wio.py`, `services/*` (6), `decoders/*` (4), `orchestrator/models.py:5` (4-model queue, `qwen/qwen3.8-27b` orchestrator, no llama), `groq_client.py:12`, `rade/policy.py`
